# Локальные ВМ: проверка установки, 2026-11-03

Проверены подготовленные Ubuntu 26.10 и Fedora 44. Это одноразовый локальный
стенд; адреса и пароли доступа в репозиторий не добавляются. Debian 13 сохранён
без установки проекта.

## Подготовка

- На Ubuntu установлены пакеты Docker, Compose и Buildx; на Fedora — Moby,
  Compose и Buildx. Состояние Docker проверено на обеих машинах.
- Fedora работает с включённым SELinux (`Enforcing`). Для стабильного SSH её
  первый адаптер временно переводился из Wi-Fi bridge в VirtualBox NAT с локальным
  пробросом TCP 2222 → 22 и UDP 51830. После испытаний адаптер возвращён в
  исходный bridge; временные правила проброса удалены.
- Попытки сделать живые снимки Debian и Fedora зависли при сохранении памяти.
  Снимки не созданы; обе машины перезапущены и работают. Живые снимки на этом
  хосте для продолжения теста не использовать.

## Найденный дефект и проверка исправления

На Fedora обычный bind mount каталога с меткой `admin_home_t` не позволил
контейнеру прочитать тестовый файл (код выхода 1). Тот же mount с `:Z`
прочитал файл (код выхода 0). Поэтому приватные каталоги каждого контейнера
помечены `:Z`, а каталоги, общие для панели и службы Основного узла, — `:z`.

Обновлённый `docker-compose.cells-cell.yml` на Fedora прошёл реальный
`docker compose run` с чтением из `cell-data`; конфигурация Основного узла из
`docker-compose.yml` и `docker-compose.cells-main.yml` прошла `docker compose
config --quiet` на Fedora. Два последовательных контейнера также прочитали
один общий каталог с `:z` (оба вернули код 0). Эта проверка подтверждает права
к файлам и разбор
Compose, но пока не подтверждает запуск AWG или связь Узла с Ячейкой.

## Дальше

Сборка образа `awg-easy-3:lab` шла на Ubuntu через
`docker build --network host --progress=plain`; её журнал находится в
`/tmp/awg-easy-build.log`. 3 ноября все три ВМ штатно выключены по SSH по
просьбе владельца, поэтому сборка прервана до завершения. При продолжении
сначала проверить журнал и наличие образа, затем повторить сборку с кэшем.

После сборки установить Основной узел, загрузить тот
же образ на Fedora и проверить регистрацию Ячейки, применение настроек и
реальный пользовательский маршрут. В локальном стенде нет внешнего IPv6 и
условий публичной DHT; для них по-прежнему нужны отдельные VPS.
