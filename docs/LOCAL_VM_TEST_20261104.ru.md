# Локальные ВМ: Основной узел и Ячейка, 4 ноября 2026

Собран текущий образ из Dockerfile, включая тест исправления AWG multi-IP.
Ubuntu 26.10 используется как Основной узел, Fedora 44 — как Ячейка;
Debian 13 пока зарезервирован для следующей проверки. Для надёжного SSH
вместо Wi-Fi bridge временно используется общая VirtualBox NAT Network
`awg-release-lab`, пробросы SSH слушают только loopback хоста. Исходный
адаптер обеих машин — MediaTek Wi-Fi bridge; после испытаний вернуть его.

## Исправленные дефекты

1. Fedora с SELinux Enforcing запрещала `sock_file:watch` для управляющего
   сокета AWG. Это подтверждено AVC и strace: `inotify_add_watch` возвращает
   EACCES; интерфейс исчезает после завершения демона. Установщики получают
   минимальный CIL-модуль `awg_easy_3_socket_watch`: разрешается только watch
   от `container_t` к `container_file_t:sock_file`. Правило действует на этот
   общий тип контейнеров; доступ к содержимому файлов/сокетов не расширяется,
   MCS и SELinux остаются включёнными. Глобальные boolean не меняются.
2. После задержки более пяти минут Ячейка повторяла старую подпись регистрации,
   даже если приглашение ещё не истекло. Перед повтором подпись обновляется
   тем же ключом, идентификатор запроса и постоянные AWG-ключи сохраняются.
   Регрессионный тест проверяет задержку и повтор после потери ответа.

## Подтверждённое состояние

- Панель Ubuntu здорова, служба Основного узла запущена через Compose.
- Ячейка установлена `install-cell.sh`, зарегистрирована по AWG; постоянный
  план и пользовательский интерфейс созданы, ревизия 1 получена и применена.
- Fedora остаётся в SELinux Enforcing. TLS и сертификаты для этой регистрации
  не использовались.
- На Windows: 798 успешных проверок, 16 пропусков Linux/явно включаемых
  проверок ядра, ошибок нет. Проверка SELinux helper включена в этот прогон.

Реальный пользовательский маршрут, вторая Ячейка, reboot и перенос состояния
ещё требуют проверки. Этот документ не подтверждает готовность к релизу.
Образы, приглашения, журналы с приватными данными хранятся только в
игнорируемом `private-test-access` и на одноразовых ВМ.
