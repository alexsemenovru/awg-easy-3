# Локальные ВМ: Основной узел и Ячейка, 4 ноября 2026

Собран текущий образ из Dockerfile, включая тест исправления AWG multi-IP.
Ubuntu 26.10 используется как Основной узел, Fedora 44 — как Ячейка;
Debian 13 пока зарезервирован для следующей проверки. Для надёжного SSH
вместо Wi-Fi bridge временно используется общая VirtualBox NAT Network
`awg-release-lab`, пробросы SSH слушают только loopback хоста. Исходный
адаптер обеих машин — MediaTek Wi-Fi bridge; после испытаний вернуть его.

## Исправленные дефекты

1. Fedora с SELinux Enforcing запрещала `sock_file:watch` для управляющего
   сокета AWG. Это подтверждено AVC и strace: `inotify_add_watch` возвращает
   EACCES; интерфейс исчезает после завершения демона. Установщики получают
   минимальный CIL-модуль `awg_easy_3_socket_watch`: разрешается только watch
   от `container_t` к `container_file_t:sock_file`. Правило действует на этот
   общий тип контейнеров; доступ к содержимому файлов/сокетов не расширяется,
   MCS и SELinux остаются включёнными. Глобальные boolean не меняются.
2. После задержки более пяти минут Ячейка повторяла старую подпись регистрации,
   даже если приглашение ещё не истекло. Перед повтором подпись обновляется
   тем же ключом, идентификатор запроса и постоянные AWG-ключи сохраняются.
   Регрессионный тест проверяет задержку и повтор после потери ответа.
3. Служба Основного узла не видела UAPI пользовательского AWG-интерфейса
   панели: отдельные tmpfs `/run` скрывали сокет, поэтому проверка владения
   закрывала маршрутизацию. В обоих Main Compose overlay добавлен общий
   приватный `cell-status/uapi` только для сокетов `/run/amneziawg`.
4. Firewalld Fedora блокировал пользовательский UDP и пересылку между AWG.
   Трассировка nft подтвердила завершающий reject firewalld после разрешения
   наших правил. Установщики открывают выбранные UDP-порты в зоне WAN и
   привязывают только зарезервированные AWG-интерфейсы к `trusted`.
   Наши более ранние nft hooks продолжают ограничивать Home/Guest/GeoIP.
   Настройки применяются к runtime и permanent без общего `--reload`.
5. Debian 13 предоставляет Compose v2 пакетом `docker-compose`; добавлен
   выбор этого пакета только при candidate v2, с отказом для v1/отсутствия.
6. Проверка двух Ячеек выявила незавершённый Home-транзит между ними через
   Основной узел и Docker `FORWARD=DROP` для межсерверных интерфейсов.
   Добавлены отдельный Home-путь через Main (без подмены интернет-выхода) и
   точные правила совместимости DOCKER-USER для доказанно принадлежащих
   проекту интерфейсов. Ошибка этой настройки удерживает защитные блокировки;
   чужое изменение правила не перезаписывается. Повторный полевой прогон
   этого исправления пока не завершён.

## Подтверждённое состояние

- Панель Ubuntu здорова, служба Основного узла запущена через Compose.
- Ячейка установлена `install-cell.sh`, зарегистрирована по AWG; постоянный
  план и пользовательский интерфейс созданы, ревизия 1 получена и применена.
- Fedora остаётся в SELinux Enforcing. TLS и сертификаты для этой регистрации
  не использовались.
- Через API создан реальный Home-клиент с входом через Ячейку, назначение
  подтверждено, native-конфиг экспортирован. Из отдельного контейнера-клиента
  установлено AWG-соединение, доступна панель Основного узла через межсерверный
  канал, проходит интернет-трафик через Ячейку. После перевода в Guest доступ
  к панели блокируется, интернет сохраняется.
- После Guest → Home доступ к панели возвращается. После штатного reboot
  Fedora по SSH та же Ячейка восстанавливает регистрацию и применённую ревизию;
  прежний профиль снова открывает панель и передаёт интернет-трафик.
- На Windows: 798 успешных проверок, 16 пропусков Linux/явно включаемых
  проверок ядра, ошибок нет. Проверка SELinux helper включена в этот прогон.
- Итоговый Linux-прогон текущего исходного кода: **817/817, без пропусков**,
  включая права, блокировки, Unix-сокеты и настоящий nft kernel readback.
  В тестовый контейнер добавлены только инструменты проверки `git` и
  `util-linux`; он использует отдельное network namespace. Три nft-теста
  исправлены на сравнение рабочим fingerprint, который сохраняет порядок
  правил внутри цепочки, но допускает перестановку деклараций ядром.
- Debian подключён второй Ячейкой. Обе Ячейки одновременно зарегистрированы,
  применяют собственные ревизии; отдельные профили через каждую открывают
  панель и передают интернет-трафик. Прямой Home-транзит между ними проверяется
  после исправления, описанного выше. Debian тоже временно переведён в общую
  NAT Network; исходный адаптер — тот же Wi-Fi bridge.

Home-транзит между Ячейками, reboot Основного узла и перенос состояния
ещё требуют проверки. Этот документ не подтверждает готовность к релизу.
Образы, приглашения, журналы с приватными данными хранятся только в
игнорируемом `private-test-access` и на одноразовых ВМ.
