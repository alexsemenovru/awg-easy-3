# AWG-Easy 3 — 0.1.2

Стабильный выпуск после испытаний установщика, туннелей и обновления на временном VPS.
Переключатели IPv4/IPv6 остаются отдельной будущей задачей.

## Что изменилось

- Диагностика больше не сохраняет старые выборки после ошибок и сбросов счётчиков.
  Недавний handshake не выдаётся за гарантию присутствия устройства сейчас.
- Когда связь не подтверждена, скорость скрыта в основной строке клиента.
  В «Диагностике» остаются отправка/приём сервера и пояснение:
  «Отправлено сервером; доставка не подтверждена». Повторные UDP-пакеты
  отключённому клиенту могут увеличивать TX — это не подтверждение их доставки.
- Чистая установка выбирает свободный случайный UDP-порт в диапазоне
  20000–60000, кроме 51820. Явно заданные и сохранённые порты не меняются.
- Проверка стабильных обновлений после загрузки ОС включена по умолчанию.
  Используются штатные механизмы systemd/OpenRC, без дополнительного контейнера.
  Обновление сохраняет состояние, пропускает намеренно остановленный VPN и
  откатывает неудачную замену на прежний кешированный образ. RC не устанавливаются.
- Исправлен порядок firewall-правил Home→Home для IPv6; изоляция Guest сохранена.
- Добавлены credits автора, согласованное оригинальное SVG/Pride-оформление —
  «Защита от чертей». Это визуальная позиция проекта, не механизм ограничения доступа.
- Уточнена подсказка ручного копирования профиля на всех пяти языках.
- Исправлена конфигурация Dependabot: еженедельные PR для GitHub Actions и базовых
  Docker-образов, без автоматического слияния. Обновления Node-зависимостей пока
  ручные: [поддержка pnpm 11 в Dependabot ещё открыта](https://github.com/dependabot/dependabot-core/issues/14794).

## Обновление

```bash
sudo awg-easy-3 update
sudo awg-easy-3 status
sudo awg-easy-3 auto-update status
```

Команда `update` сохраняет клиентов, ключи, пароль и выбранный порт. Не используйте
`reinstall` для обычного обновления: он намеренно очищает настройки. Для обновления
нужен чистый управляемый Git-клон без собственных изменений отслеживаемых файлов.
История RC сохранена: переход с rc.1/rc.2 на стабильную 0.1.2 не требует переустановки.

Автоматическую проверку можно отключить:

```bash
sudo awg-easy-3 auto-update disable
```

Новые установки используют образ `ghcr.io/alexsemenovru/awg-easy-3:0.1.2`.
Если у провайдера включён внешний firewall, разрешите выбранный установщиком UDP-порт.

## Проверки и ограничения

- Реальный Ubuntu/systemd VPS: установка Docker/Compose, IPv4/IPv6-туннели,
  Home/Guest, отзыв доступа, управление, удаление/переустановка и перезагрузка.
- Обновление и откат после плохого healthcheck/SIGTERM проверены с реальным
  Docker/Compose и локальным тестовым источником релизов. Чужой Docker-сервис
  и мониторинг провайдера сохранены.
- Телефонное переключение и контрольная проба сопоставлены с AWG RX/TX и пакетами.
  Исходный триггер остаточной отправки из видео не установлен задним числом.
- Последующие UI-правки проверены локально на пяти языках, в мобильной вёрстке
  и RTL, включая ошибки API. Финальный образ не проверялся на уничтоженном VPS.
- OpenRC ещё требует реального стенда. Обнаружение mDNS/SSDP зависит также от
  использования VPN-интерфейса приложением клиента. Откат не защищает от SIGKILL,
  потери питания, повреждения диска или несовместимой миграции будущих версий.

[Подробный отчёт](https://github.com/alexsemenovru/awg-easy-3/blob/v0.1.2/docs/VPS_TEST_2026-08-30.ru.md).

## English summary

Stable 0.1.2 combines safer live diagnostics, random free install ports, native
boot-time stable update checks with rollback, the VPS-tested IPv6 Home rule-order
fix, author credits and approved original Pride branding ("Protection against
devils"). Unconfirmed peers keep server-side rates in Diagnostics only, with
an explicit delivery warning. Updates preserve existing state and ports.
Real-host validation covered Ubuntu/systemd; OpenRC remains field-unverified.
Final UI changes were locally browser-tested, not redeployed to the destroyed VPS.
Dependabot now proposes Actions/base-image updates; pnpm 11 updates remain manual.
Per-client IP-family switches are not included.
