# AWG-Easy 3 — 0.1.2-rc.1

Тестовый кандидат. **Не стабильный релиз: испытания на VPS ещё не завершены.**
Stable `0.1.1` и контейнерный тег `latest` остаются без изменений.

## Что изменилось

- Более надёжные замеры скорости: последовательный опрос, сброс устаревших
  результатов и явные состояния «Измерение…» / «Данные недоступны».
- Статус «Недавняя связь» честно отражает возраст handshake, а не гарантирует
  текущее подключение. Причина наблюдения 170–230 бит/с требует полевого теста.
- Случайный свободный UDP-порт чистой установки с проверкой сокетов и Docker;
  сохранённый порт при обновлении не меняется.
- Credits автора, утверждённый SVG-значок и фон «Защита от чертей».
- Проверка стабильных обновлений после загрузки ОС включена по умолчанию на
  systemd/OpenRC. Управление: `sudo awg-easy-3 auto-update enable|disable|status|run`.
- Обновление проверяет версию и совместимость состояния, заранее загружает
  образ, сохраняет профили и откатывает неудачную замену на прежний образ.
  Это не резервное копирование и не защита от отключения питания.

## Как тестировать

На отдельном Linux/amd64 VPS без существующей установки AWG-Easy 3:

```bash
git clone --branch v0.1.2-rc.1 https://github.com/alexsemenovru/awg-easy-3.git awg-easy-3-rc
cd awg-easy-3-rc
sudo ./install.sh
```

Образ: `ghcr.io/alexsemenovru/awg-easy-3:0.1.2-rc.1`.
Обычная команда `update` и автообновление **не устанавливают RC**.
Не очищайте рабочий сервер ради этого теста и не публикуйте профили/ключи.

[Полный чек-лист VPS](https://github.com/alexsemenovru/awg-easy-3/blob/v0.1.2-rc.1/docs/RELEASE_TEST.ru.md)
и [изменения](https://github.com/alexsemenovru/awg-easy-3/blob/v0.1.2-rc.1/CHANGELOG.md).
Переключатели IPv4/IPv6 не включены: они остаются следующим этапом.

## English summary

Test candidate only; VPS validation is pending. Includes more robust live
diagnostics, random clean-install UDP ports, author credits, approved Pride
branding, and default-on boot-time stable updates with failure rollback.
Stable `0.1.1` and `latest` are unchanged. Stable updates never select RC tags.
The installer above explicitly opts a disposable Linux/amd64 test VPS into this
candidate. Per-client IPv4/IPv6 controls are not part of this release.
