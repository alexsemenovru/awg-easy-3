# AWG-Easy 3 v0.1.5

## Русский

Косметический патч: скачивание конфигураций, web-приложение и описание клиентов.

- `.conf` выдаётся с `application/octet-stream`, а не `text/plain`, чтобы браузеры
  Android не дописывали текстовое расширение. В обоих параметрах имени файла
  `Content-Disposition` используется совместимое имя без пробелов, до 15 ASCII-символов
  перед `.conf`: например, `Honor_50.conf`. Неподходящие имена получают безопасное
  `AWG-client.conf`. Имя клиента в панели и содержимое профиля не изменяются.
- Дополнен существующий web-app manifest: стабильный идентификатор, описание,
  правильный MIME-тип и обновление без устаревшего кэша; добавлены метаданные для
  домашнего экрана Apple. Используются прежние значки 192/512 px и Apple Touch Icon.
  Установка или создание ярлыка выполняется из меню браузера. Автоматическое
  предложение PWA обычно требует HTTPS: HTTP-адрес внутри VPN не гарантирует его.
  Service worker, офлайн-кэш профилей и публичный доступ не добавляются.
- Все пять README описывают AmneziaWG и кандидатов Throne/Mihomo с точными версиями
  и границами проверки. Пользователь подтвердил подключение и открытие IPv4/IPv6-панели
  на Honor 50 с AmneziaWG (приложение 3.1.20260813, backend 3.1.20260814).
  Throne и Mihomo не объявляются проверенными на доступ к нашей IPv6-панели.

```bash
sudo awg-easy-3 update
```

Переимпорт не нужен. Движок AWG v3.1.20260828, ключи, пароль, клиенты, адреса,
маршруты, разрешения и формат состояния не меняются. Замена контейнера может
ненадолго прервать связь. После обновления обновите страницу панели.

Регрессионные тесты проверяют MIME-тип, заголовки, безопасные имена, неизменность
текста профиля, манифест, значки и документацию. Фактическое имя загрузки и способ
установки web-приложения зависят от браузера; новый патч ещё требует проверки на
Android пользователем. Успешный тест AmneziaWG выше относится к прежнему файлу,
переименованному вручную, а не к новому механизму скачивания.

## English

Cosmetic patch for configuration downloads, web-app metadata and client guidance.

- Serve `.conf` as `application/octet-stream` instead of `text/plain` to avoid
  Android browsers appending a text extension. Both download filename parameters
  use an ASCII tunnel name of at most 15 characters before `.conf`, without spaces
  (e.g. `Honor_50.conf`), with `AWG-client.conf` as a safe fallback.
  Displayed client names and profile contents are unchanged.
- Complete the existing manifest with a stable ID, description, correct MIME type
  and revalidation; add Apple home-screen metadata. Reuse the existing icons.
  Use the browser's install/add-to-home-screen command where available. Automatic
  PWA promotion generally requires HTTPS, not the private VPN HTTP address.
  No service worker, offline profile cache or public exposure is introduced.
- Update all five READMEs: AmneziaWG on Honor 50 has user-confirmed connection and
  IPv4/IPv6 panel access; Throne and Mihomo remain evaluation candidates, not
  IPv6-panel-certified replacements.

Run `sudo awg-easy-3 update`, then refresh the panel. No reimport or state migration
is required; the engine, credentials, clients and networking remain unchanged.
Container replacement may briefly interrupt connections. Download headers/names,
profile bytes, manifest/icons and documentation have regression coverage; the new
download behavior and web-app installation still need device/browser field testing.
