# AWG-Easy 3 v0.1.4

## Русский

Обновление движка AmneziaWG без переимпорта клиентских профилей.

- `amneziawg-go` обновлён с `v3.1.20260814` до официального тега
  **`v3.1.20260828`**, закреплённого коммитом
  `b5928efb6ca19f0153958460c3d141f04abc5c2e`.
- Случайное дополнение пакетов теперь ограничивается изученным UDP-окном peer:
  исправлен расчёт padding около предельного размера пакета.
- Исправлена обработка handshake под нагрузкой при `DisableCookies=true`:
  сервер больше не требует cookie, ответ с которым сам же запрещает.
- `amneziawg-tools` остаётся на актуальном официальном `v3.1.20260812`
  (`ee0f0a9aa34ff0a0da4b3433b9512781cfe02843`). Новых официальных бета-версий,
  подходящих под согласованные условия, на момент проверки не найдено;
  незавершённые PR и альфа-изменения не включены.
- README на английском, русском, фарси, испанском и китайском перестроены:
  описание → краткие возможности → установка и первый вход → управление →
  технические подробности и ограничения.

### Обновление

```bash
sudo awg-easy-3 update
```

Используйте `update`, а не `reinstall`. Сохраняются клиенты, ключи, пароль панели,
порты, адреса, разрешения IPv4/IPv6 и экспортируемые профили. Формат состояния,
DNS, маршруты и параметры обфускации не меняются. При замене контейнера возможен
кратковременный разрыв связи; импортировать профиль заново не требуется.

### Проверки

Перед публикацией обязательны тесты приложения и оболочки, сборка образа,
регрессионные проверки двух исправлений движка, реальные AWG-соединения
со старым движком клиента, замена образа 0.1.3 → 0.1.4 → 0.1.3 с неизменными
профилями и проверка двусторонних разрешений IPv4/IPv6 в изолированных контейнерах.

Новый VPS и новые ручные испытания Android/Windows для этого выпуска не
используются. Контейнерная проверка не заменяет матрицу клиентских DNS,
мобильного multicast и внешней сети провайдера. Ранее описанные ограничения
IPv6-only DNS и Home discovery остаются в силе.

## English

Updates the AWG engine to official **v3.1.20260828**, pinned to
`b5928efb6ca19f0153958460c3d141f04abc5c2e`, without changing existing profiles.

- Clamp random packet padding to the peer's learned UDP window.
- Fix handshakes under load when cookies are explicitly disabled.
- Keep the current official `amneziawg-tools` v3.1.20260812 revision.
- Reorganize all five READMEs around introduction, brief features, installation
  and first login, management, then technical details.

Run `sudo awg-easy-3 update`. Existing clients, keys, password, ports, addresses,
IP permissions and exported profiles are retained. No DNS, routing or state-format
migration is introduced. Container replacement may briefly interrupt connections.

Release checks cover application/shell tests, image build, targeted upstream
regressions and real old-client/new-server AWG traffic, image upgrade/rollback,
unchanged state/exports, Home/Guest isolation and IPv4/IPv6 permissions in isolated
Linux containers. This is not a new VPS or Android/Windows field test; the known
client DNS and multicast limitations remain unchanged.
