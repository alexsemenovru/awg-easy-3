# AWG-Easy 3 — 0.1.2-rc.2

Тестовый кандидат, не стабильный релиз. Продолжаются испытания на VPS.

## Исправлено после rc.1

На реальных AWG-туннелях найден дефект порядка firewall-правил: общее
запрещение межклиентского трафика срабатывало раньше разрешения Home→Home
для IPv6. IPv6-интернет при этом работал, но два Home-клиента не могли
связаться по внутренним IPv6-адресам.

Теперь разрешения Home для обеих семей стоят перед общим правилом изоляции.
Точечное исправление проверено на VPS с двумя изолированными AWG-клиентами;
добавлен регрессионный тест порядка правил. Для тестов используйте rc.2
вместо rc.1. Новые переключатели IPv4/IPv6 не реализованы этим исправлением.

Включены и предыдущие изменения: диагностика, случайный UDP-порт, credits,
Pride-оформление и обновления стабильных версий после загрузки ОС.

## Установка на тестовый Linux/amd64 VPS

```bash
git clone --branch v0.1.2-rc.2 https://github.com/alexsemenovru/awg-easy-3.git awg-easy-3-rc
cd awg-easy-3-rc
sudo ./install.sh
```

Образ: `ghcr.io/alexsemenovru/awg-easy-3:0.1.2-rc.2`.
Обычный `update` и автообновление не устанавливают RC.
`master`, стабильный образ `0.1.1` и `latest` не меняются.

[Чек-лист испытаний](https://github.com/alexsemenovru/awg-easy-3/blob/v0.1.2-rc.2/docs/RELEASE_TEST.ru.md).
Не публикуйте пароли, ключи и ссылки профилей из установочного вывода.

## English summary

RC2 fixes a firewall ordering bug discovered on a real VPS: an inter-peer drop
shadowed the IPv6 Home permit. Both Home permits now precede isolation. IPv6
Internet access was unaffected. Use RC2 instead of RC1 for testing. Includes
all RC1 features, but not the future per-client IP-family switches. Stable
`0.1.1` and `latest` remain unchanged; field validation is still in progress.
