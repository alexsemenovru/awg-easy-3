# Языки установщика — 5 ноября 2026

Причина дефекта: `--lang` передавался только в контейнер для начального языка
панели; сообщения shell-установщика и CLI инициализации оставались английскими.

Исправлено для `en`, `ru`, `fa`, `es`, `zh-cn`:

- Вопросы, справка, ошибки, установка зависимостей, меню существующей
  установки, подтверждение удаления, инструкции NixOS и итоговые сообщения.
- Первоначальный вывод пароля, адреса панели и первого `vpn://`-профиля.
  Значения пароля и ссылки выводятся буквально, без интерпретации как формата.
- Язык выбирается до разбора остальных параметров; работает и
  `--help --lang ru`. Документированный синтаксис — `--lang ru`;
  также принимается `--lang -ru`. `AWG_LANG=ru` остаётся поддержанным.
- Подтверждения принимают русские, испанские, персидские и китайские ответы.
  Неизвестный ответ и закрытый ввод не подтверждают удаление.

Единый каталог — `src/lib/InstallerMessages.json`. Shell-каталог
`lib/installer-i18n.sh` генерируется командой
`node scripts/build-installer-i18n.cjs`; проверка актуальности — с `--check`.
На VPS для перевода не нужны Node на хосте, Python, gettext или установленная
локаль. Node внутри штатного контейнера использует тот же каталог.

безопасные запуски справки/ошибок установщика через POSIX-режим Git Bash,
все сообщения на пяти языках с `LC_ALL=C`, вопросы выбора адреса,
подтверждения удаления, CLI инициализации, существующие проверки портов,
