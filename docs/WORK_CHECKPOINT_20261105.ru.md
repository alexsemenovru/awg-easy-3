1. Полная продуктовая регрессия Main/Cell при потере UDP, резервной связи,
   reboot без Main, смене адреса и утрате начальных DHT-контактов. Сохранить

   Файловое копирование и ключ архива сами по себе не разрешают takeover.
3. Согласованное только возрастающее обновление Main/Cell с проверенным пакетом
   и автоматическим подтверждением. До этого панельный updater Main удерживается;
   ежедневное расписание проверки внедрено 6 ноября (`02023e42`), механизм
   согласованной установки Main/Cell остаётся незавершённым.

   peer не равно завершённой кнопке удаления VPS-контейнера.
5. Согласованный первый слой минимизации/обфускации сохраняемых метаданных,
   оставшиеся элементы UI (диагностика Ячеек, переименование профиля), итоговая
   проверка установщика/обновления, TOTP и мобильного интерфейса.

### Точная точка продолжения

1. `restore-cli.js prepare`/`inspect` возвращают `activated:false`: подготовка
   завершена, автоматическая активация рабочей установки **ещё не реализована**.
   Нужны предыдущий снимок, транзакционное переключение каталогов/host bindings,
   восстановление после прерывания и сквозной Main+Cell через пользовательскую
   команду. Не копировать старые kernel ownership journals.
2. Учесть границу необратимости: после принятия Ячейкой новой live authority
   автоматический возврат к прежнему Main не вернёт её доверие. Откат файлов
   допустим до выдачи takeover; после неё нужна согласованная recovery-операция,
   а не обещание обычного healthcheck rollback.
3. Проверить новый recovery locator в DHT: историческая identity ещё используется
   для обнаружения, старая копия не может подписать новую live authority, но её
   влияние на доступность locator не устранено. Внешний IPv6 endpoint migration
   не реализован; внутренние IPv4/IPv6 VPN не выключались.
4. Завершить согласованные forward-only обновления Main/Cell с проверенным
   подписанным пакетом и автоматическим ack. Ежедневное расписание реализовано,
   но оно не подменяет этот механизм.
5. Завершить продуктовый отзыв/удаление контейнера Ячейки и собственных ресурсов,
