# Передача состояния — 5 ноября 2026

Ветка `codex/cells-foundation`. Это состояние разработки, **не готовый релиз**.
Пароли стендов, реальные профили и ключи в Git не добавлены.

## Учёт согласованного ресурса

Первоначальный бюджет 5/5 израсходован ранее. Затем владелец выделил ещё
семь пятичасовых циклов с обязательным сохранением на GitHub после седьмого.
До текущего запроса консервативно учтены четыре раунда: 26 и 29 октября,
3 и 4 ноября. Раунд 5 ноября начат как пятый; в ходе непрерывной работы
естественно обновилось окно квоты аккаунта, после чего работа продолжилась.
Для ограничения бюджета считаем это шестым из семи: **остаётся один цикл**.
Ручной сброс в этом запросе не применялся. Отдельного достоверного исторического
счётчика квоты по проекту нет; глобальная квота аккаунта не равна его затратам.
Дальше не обещать дополнительные циклы без решения владельца.

## Реализовано и сохранено

- `c2c88010`: рабочий ограниченный DHT-worker, BEP44, собственная mutable-запись,
  сохранённые начальные контакты, порт установщика. Три разные локальные ВМ
  обнаружили друг друга; повтор после потери первоначального хранителя прошёл.
- `bb519d93`: резерв только управляющего AWG через подписанный технический
  TCP-транспорт, не более одного посредника. Автоматический точный nft redirect
  с журналом и проверкой владения не меняет AWG Endpoint и пользовательский выход.
- `9544541f`: старые TLS-транспорт, генератор сертификатов и TLS-стенд удалены.
  Внешние HTTPS-загрузки остаются; это не транспорт регистрации/управления.
- `77f39c1a`: минимальный подписанный статус служебного пути в панели, пять языков,
  отсутствие данных отличается от отключения. Никакой клиентской телеметрии.
- `728b52b5`: восстановление ранее применённой подписанной маршрутизации Ячейки
  после boot без свежего Main handshake. Новая ревизия требует живого data-link;
  владение/политики и закрытый недоступный выход проверяются как раньше.
- `34b8a350`: ограниченный зашифрованный снимок файлов, приватный staging,
  сохранение ULA/профилей/TOTP и замена старых сессий при подготовке restore.
  Это библиотека подготовки, **не законченная система backup/restore**.

Локальный полный Linux-прогон последнего кода: **868/868, без пропусков**.
Подписанный управляющий RPC прошёл через реальный AWG и посредника в разных
network namespace при заблокированном исходном UDP. Публичная межрегиональная
DHT и полная служба с резервом на двух VPS в этом раунде не проверялись.
Образ с новой зависимостью DHT проверяется отдельно; не смешивать запуск
исходников поверх прежнего lab-образа с завершённой сборкой Dockerfile.

## Оставшиеся блокирующие работы

1. Полная продуктовая регрессия Main/Cell при потере UDP, резервной связи,
   reboot без Main, смене адреса и утрате начальных DHT-контактов. Сохранить
   невозможность обходного выхода, Home-группы, GeoIP и обе семьи адресов.
2. Поколения backup, подтверждения Ячеек, fencing старого управления,
   транзакционное восстановление на новом хосте и предыдущий снимок перед ним.
   Файловое копирование и ключ архива сами по себе не разрешают takeover.
3. Согласованное только возрастающее обновление Main/Cell с проверенным пакетом
   и автоматическим подтверждением. До этого панельный updater Main удерживается;
   ежедневное расписание проверки ещё не внедрено.
4. Завершение удаления Ячейки: авторизованное поручение, собственные ресурсы,
   контейнер и подтверждение; обработка недоступной Ячейки. Наличие плана удаления
   peer не равно завершённой кнопке удаления VPS-контейнера.
5. Согласованный первый слой минимизации/обфускации сохраняемых метаданных,
   оставшиеся элементы UI (диагностика Ячеек, переименование профиля), итоговая
   проверка установщика/обновления, TOTP и мобильного интерфейса.

При завершении ресурса сохранить **реальный** статус на GitHub без тега релиза.
Не переносить молча согласованные функции за пределы выпуска и не называть
систему готовой при незавершённых пунктах.

## Стенды и артефакты

Новая инструкция владельца от 5 ноября заменяет прежние адреса/ОС:
Debian 13.7, Ubuntu 26.04.1 и CentOS Stream 10. Старой Fedora больше нет.
В этом раунде VirtualBox bridge не менялся; тесты работали через прямой SSH.
ВМ выключаются только штатной SSH-командой. Ключи проверяются отдельным
`private-test-access/vm-20261105-known-hosts`.

Полные обезличенные журналы, скриншоты и переносимый POSIX dependency bundle
на ноутбуке: `private-test-access/`. Рабочий helper `vm-20261105.py` читает пароль
из исходной инструкции, а не содержит его в коде. Все тестовые криптографические
идентичности одноразовые, без обращения к профилям действующих пользователей.

Подробности: [DHT](DHT_SERVICE_20261105.ru.md),
[служебный резерв](TECHNICAL_RELAY_20261105.ru.md),
[снимок backup](BACKUP_SNAPSHOT_20261105.ru.md).

## Сборка и окончание раунда

- Вся ветка отправлена в `origin/codex/cells-foundation`, включая ранее
  невыпущенные UI/TOTP/установочные изменения. Тег и релиз не создавались.
- Добавлен CI `cells-development.yml`: сборка исходного Dockerfile, полный
  Linux-прогон с nft kernel checks и настоящий управляющий RPC через резерв.
  Образы/пакеты он **не публикует**. Успех CI не подразумевать до чтения результата.
- В WSL Ubuntu 22.04 установлен Docker 29.1.3 с Buildx. Демон настроен без
  iptables/ip6tables, bridge и изменения forwarding. В конце Docker, socket и
  containerd остановлены и отключены от автозапуска. Они до этого отсутствовали.
- Исходники для сборки: `/opt/awg-build-20261105`, соответствуют `34b8a350`.
  Слой `node-deps` построен из настоящего Dockerfile с frozen lockfile;
  **15/15** DHT/backup-проверок прошли на его Node 22.18.0.
- Полный образ локально **не подтверждён**: загрузка GCC из Alpine шла около
  120 КБ/с. Сборка остановлена при установке GCC/G++; не считать эту остановку
  ошибкой исходников или успешной сборкой. Кэш сохранён в WSL, журналы
  `wsl-production-*-20261105.log` скопированы в `private-test-access`.
- Yandex 26.10.0.1860 успешно отрисовал отдельную тестовую страницу через
  браузерный протокол с новым временным профилем. Проверка `--dump-dom` не
  завершалась, поэтому доказательством считается успешная протокольная проверка,
  а не команда версии. Контрольная проверка использовала временный профиль;
  параметры запуска обычного браузера не менялись.
- Все три ВМ выключены штатно через SSH, `VBoxManage list runningvms` пуст.
  VirtualBox применялся только для headless-запуска/проверки состояния, не poweroff.
