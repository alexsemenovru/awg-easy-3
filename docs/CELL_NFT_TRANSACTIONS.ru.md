# Транзакции firewall маршрутизирующих Ячеек

`CellNftTransaction` применяет только `inet awg_easy_3_routes`. Ожидаемый JSON
создаётся компилятором заранее. Приватный атомарный журнал хранит подтверждённый
снимок и незавершённое намерение; запись намерения предшествует изменению ядра.

Каждая замена — один атомарный nft JSON-пакет, с dry-run и проверкой readback.
При ошибке возвращается прежний снимок. При перезапуске незавершённое обновление
также откатывается. Сопоставление допускает только точные ранее сохранённые
снимки; чужие/изменённые таблицы не присваиваются и не удаляются.

Компонент вызывает внешний durable guard и **никогда сам его не снимает**,
включая успешное применение и успешный откат. Безопасность всей конфигурации
должен подтвердить общий координатор, а не один firewall-компонент.

## Проверки 19 сентября 2026

Восемь unit tests: успешное применение/no-op/удаление, чужая таблица, отказ nft,
перезапуск до/после применения, потеря таблицы, ошибка записи, чужие изменения,
отказ guard, повреждение журнала и независимость от мутации входного объекта.

Весь изолированный AWG routing lab переведён на предвычисленный JSON и журнал.
Матрица IPv4/IPv6, Home/Guest, GeoIP, обрыв туннеля, ошибочное изменение маршрутов
прошла. Дополнительный сценарий сохранил намерение новой политики, применил её
к ядру, создал новый экземпляр компонента и восстановил прежнюю политику из
журнала. До явной проверки guard продолжал блокировать оба семейства.

Полный JS-прогон: 357 тестов, 353 passed, 4 skipped, 0 failed.

## Что ещё не готово

Общий durable координатор AWG/routes/nft, межпроцессный lock, владение и жизненный
цикл AWG-интерфейсов, порядок запуска после reboot и подключение к установщику.
Отдельные успешные транзакции маршрутов и firewall ещё не означают атомарную
смену всей топологии. Текущий стенд владеет своей изолированной сетью целиком;
его проверка интерфейсов не является продуктовым механизмом владения.
