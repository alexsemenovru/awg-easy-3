# Дополнительный функциональный цикл — 10 ноября 2026

Владелец выделил ещё один цикл, начатый при 27% использованной квоты
(73% оставалось). Ручной сброс не применялся. Цикл дизайна/README/bugreport
не начинался. Публикация релиза не выполнялась.

## Изменения

- Раздельный исходящий IPv4: `--egress-ipv4` / `AWG_EGRESS_IPV4` установщика,
  предложение при нескольких локальных адресах, проверка назначения WAN и
  маршрута. В Ячейке — локальный `AWG_CELL_EGRESS_IPV4`. Настройка проходит
  через bootstrap, состояние, оба компилятора NAT, compose и restore.
  SNAT ограничен пересылаемым VPN-трафиком с собственных входных интерфейсов;
  служебный/локальный трафик VPS не подменяется. Отсутствие исходящего IPv4
  у нового сервера очищает старую привязку, а не переносит чужой адрес.
- `geoRoute`: выбранные страны либо всё, кроме них, через отдельный выход;
  общий выход профиля остаётся для остальных направлений. Отдельная настройка
  блокировки GeoIP сохраняется. API, состояние v4, подписанная маршрутизация,
  backup/валидация и удаление Ячейки учитывают дополнительную ссылку.
  В интерфейсе добавлен сворачиваемый раздел на пяти языках.
- Компилятор маршрутов использует один ограниченный бит fwmark, сохраняет
  остальные биты и заново вычисляет собственный на входе/обратном пути.
  При утрате выбранного пути не добавляет запасной выход.
- Пакетный тест обнаружил необходимость согласовать обратную маркировку и
  `src_valid_mark=1`. Настройки применяются только к доказанно собственным
  интерфейсам; all/default/WAN не изменяются. Legacy-файл sysctl мигрируется
  только при точном совпадении с ранее генерируемым содержимым.
- Координированный updater Main/panel: root intent до остановки, одинаковый
  проверенный неизменяемый образ, запуск панели и затем Main, подтверждение
  готовности живого Main, восстановление прерванной операции только вперёд.
  Ячейки получают обновление через существующий аутентифицированный poll.
  Недоступная Ячейка остаётся ожидающей, а не считается обновлённой.
- Root supervisor Ячейки сохраняет проверенный ID образа до замены.
  При восстановлении проверяет образ и каталог состояния нового контейнера;
  не принимает посторонний контейнер по одному совпадению имени. Новая команда
  не затирает незавершённую замену; fingerprint чужой команды не помечается
  исполненным. Журнал переживает разрыв между заменой anchor и завершением.

## Уже проверено

- Пакеты в изолированных Linux namespaces с настоящим AWG: GeoIP include и
  exclude, разные выходы, явный IPv4 SNAT, IPv6 и обратный TCP-трафик,
  потеря выбранного канала без fallback. Последующие проверки всей матрицы
  продолжаются; промежуточный PASS не считать финальным результатом запуска.
- Windows suite до последних правок host sysctl: 942 теста, 867 прошли,
  ошибок нет, 75 пропущены по условиям Windows. Это не заменяет Linux suite.
- Root Linux unit-тест транзакции Main: четыре сценария, включая неверную
  подпись, отказ запуска панели и Main; все прошли до последних правок sysctl.
- Браузер: пять языков × 320/1440 px, выбор общего выхода, переименование,
  backup, удаление секрета из закрытого окна, ошибка пароля; без overflow и
  ошибок JS. Отдельный новый GeoIP form ещё требует сценария сохранения.
- Целевые тесты bootstrap/исходящего IPv4/restore/журнала обслуживания прошли.

## Запущенные проверки — результат обновить перед окончанием

- `/var/tmp/awg-verified-suite.log`: полный Linux suite, один поток,
  настоящий nft kernel, исходники `/var/tmp/awg-verified-20261110`.
- `/var/tmp/awg-physical-update-20261110.log`: настоящая замена Docker/Compose
  Ячейки, сбой после сохранения нового env и повтор. Только граница
  неопубликованного registry/signature подменена фиксированной лабораторной
  фикстурой; производственная проверка подписи не изменена.
- `/var/tmp/awg-live-verified-20261110.log`: настоящий host restore с двумя
  живыми Ячейками. Старый Main в отдельном namespace, после его остановки
  floating endpoint переносится новой машине. Предыдущие неуспешные варианты
  теста не являются доказательством готовности restore.
- `/var/tmp/awg-routing-final2-20261110.log`: полная пакетная матрица.

До успешного окончания этих проверок нельзя объявлять все обязательства
выполненными или релиз готовым. Не подменять физическую проверку Main+Cells
одними тестами shell-моков. Ошибки финальных тестов необходимо сохранить явно.

## Стенды и сохранение

- Ubuntu `192.168.1.15`, Debian `192.168.1.17`; CentOS в этом цикле не включался.
- Windows блокирует прямой LAN SSH. На выключенной Debian добавлен второй
  NAT-адаптер и localhost TCP/22236 → SSH, затем временно назначен адрес
  `10.0.3.15/24` на enp0s8. Ubuntu доступна по SSH через этот проверенный jump.
  Ключи обоих серверов проверяются прежним known_hosts. Рабочий VPN не менялся.
- Локальный игнорируемый helper: `private-test-access/vm-20261110.py`.
  `@file:PATH` читает локальный файл shell-команд. Не считать вызов завершённым,
  пока `exec_command` не вернул exit_code; проверять ошибки загрузки до сборки.
- Перед выходом забрать журналы, сохранить Git и штатно выключить Ubuntu,
  затем Debian через SSH. После выключения убрать временный NAT-адаптер Debian
  и проброс `awg-ssh`. У Ubuntu мог сохраниться неактивный natpf2 `awg-ssh`;
  его тоже убрать. WSL/Yandex Browser не изменялись.
