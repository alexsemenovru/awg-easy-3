# Полевой раунд Основного узла и Ячейки — 26 октября 2026

Две временные VPS владельца: Основной узел на Ubuntu 26.04.1 (AMS), Ячейка
на CentOS Stream 10 (MOW). Обе минимальные, около 889 МиБ RAM. Адреса,
реквизиты, приглашения и профили здесь не сохраняются. Рабочий ARN не менялся.

- Одинаковый локально собранный образ запущен на обеих VPS; Docker и nftables
  установлены. На CentOS Docker Engine не смог запустить bridge/NAT из-за
  отсутствующего расширения ядра `addrtype`; для стенда настроен Docker без
  bridge и управления iptables, что подходит сервисам проекта в host network.
- Основной узел установлен, Ячейка зарегистрировалась через одноразовое AWG
  приглашение. Постоянный служебный канал и ревизии клиентских назначений
  подтверждены. Приватный код приглашения после регистрации удалён.
- Ячейка сначала не подтверждала ревизию: `iptables-legacy` возвращает код 3
  при отсутствии необязательной legacy-таблицы на таком Docker-хосте. Узкое
  исправление отличает именно эту ситуацию от иных ошибок firewall; тесты
  покрывают оба случая. После обновления образа ревизия №1 подтвердилась.
- Data-AWG Ячейки застрял в фазе создания: у нового интерфейса
  `rp_filter=1`, а контейнер не вправе менять host sysctl. Установщик теперь
  резервирует `rp_filter=2` также для `awgdata0` и всех `awgd0`–`awgd126`;
  прежний точно известный файл sysctl обновляется без принятия сторонних
  правок. После перезапуска Ячейки data-AWG поднялся, обе стороны обменялись
  свежим handshake.
- Создан тестовый Home-профиль с входом через Ячейку. Подписанный маршрут
  сначала содержал IPv6-адрес панели, хотя межсерверный канал и Ячейка имеют
  только IPv4; Ячейка обоснованно отвергла его. Публикация теперь включает
  IPv6 панели лишь при наличии IPv6 в закреплённом data-offer.
- Следующий маршрутный прогон обнаружил несовпадение nft readback: ядро
  CentOS сортирует имена интерфейсов в анонимном наборе. Генератор теперь
  выдаёт канонический порядок. Предыдущая неудачная транзакция оставила
  защиту включённой и журнал в состоянии recovery; пользовательский трафик
  в обход маршрута не пошёл.

Последнее исправление сборки nft развёрнуто на MOW, но ранее прерванная
маршрутная транзакция остаётся в защищённом состоянии. Полный локальный прогон:
794 теста, 753 пройдены, 41 пропущен по условиям платформы, 0 ошибок.

**Не завершено в этом раунде:** восстановить защищённую тестовую маршрутную транзакцию, затем проверить
реальный Home-доступ к панели и выход через Ячейку. Подтверждение готовности
профиля пока основано на ACK назначения, а не маршрутной ревизии; UI/экспорт
поэтому могут опередить готовность. Это отдельный обязательный блокер релиза.

Исходный код и тесты сохранены; работающие VPS пока полезны для завершения
этого полевого прогона. При уничтожении стендов секреты и тестовые профили
не требуются для воспроизведения — нужен только новый чистый стенд.
