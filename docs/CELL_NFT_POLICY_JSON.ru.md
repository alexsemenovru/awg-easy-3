# Предвычисленный JSON маршрутизирующего firewall

`compileCellRouting` теперь возвращает `nftSnapshot` вместе с прежним текстом
`nftables`. Это ожидаемый декларативный снимок до изменения ядра, а не снимок,
присвоенный после применения. Он позволяет журналировать намерение заранее.

`CellNftPolicyJson` разбирает только ограниченные выражения, генерируемые нашим
компилятором; это не общий парсер nft и не формат сетевого API. Неизвестные
выражения отклоняются. GeoIP-политика отдаёт структурированные определения
наборов дополнительно к прежнему тексту; IPv4/IPv6 интервалы объединяются с
точной BigInt-арифметикой и сохраняют разрывы. Счётчики, timeout и динамические
элементы здесь не используются.

В изолированном Linux проверены 42 комбинации: Основной узел/Ячейка, GeoIP
off/block/allow, обычная конфигурация, пустая geo-база, один клиент, отсутствие
клиентов, потеря IPv6, обратный порядок имён интерфейсов, отключённый NAT66.
Для каждой совпали:

1. Предвычисленный JSON и readback прежней текстовой политики.
2. Предвычисленный JSON и readback установки через JSON-пакет.

Geo-наборы включали перекрывающиеся и смежные CIDR, диапазоны с незаполненными
промежутками, единичные адреса и оба семейства. Есть пять unit tests для
канонизации, недопустимых выражений, порядка зависимостей и 128-битных границ.

Проверка выполнена на nftables 1.1.3 из изолированного образа; это не обещание
совпадения JSON всех исторических nft-версий. При отличиях runtime должен
оставить guard, а не игнорировать неизвестные поля. Общая транзакция топологии
и интеграция со службой остаются следующими задачами.

Запуск стенда: третий аргумент `scripts/run-cell-wsl-lab.sh` — `policy-json`.
