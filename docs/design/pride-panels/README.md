# Защита от чертей — кандидат фона для следующего патча

Сохранено 2026-09-12 по просьбе автора. Основа — предоставленный им BG3.html
и видео. Самостоятельный вариант: [BG3-soft.html](BG3-soft.html).
25 сентября 2026 подключён к рабочей панели в css/pride-panels.css и развёрнут
в частной development-установке FRA. В публичном релизе пока не опубликован.

Сохранены шесть цветов, порядок полос, цикл 24 секунды и левый движущийся блик.
Подложка теперь постоянная #07111f; удалены смена её цвета и белая стеклянная
вуаль. Уменьшены тени и контраст окантовок, размытие 10 → 5 px, активная яркость
1.28 → .82, насыщенность 1.18 → .95 и масштаб 1.05 → 1.015.
Движение отключается через prefers-reduced-motion; фон не перехватывает клики.
Исходный файл автора не изменён.

При интеграции изолированы имена декоративных элементов, сохранён порядок
цветов при RTL. В браузере проверены непрозрачные карточки, мобильная ширина
390 px и RTL: нет горизонтального переполнения и ошибок консоли.
Reduced-motion закреплён тестом. Измерения нагрузки GPU/батареи ещё не проводились.
