# Проверки обновления и восстановления — 25 ноября 2026

## Обновление Ячейки

- Если Compose прерывается между удалением старого контейнера и созданием
  нового, следующий запуск берёт тот же проверенный образ из журнала.
  Повторная загрузка из реестра для продолжения этой операции не нужна.
- В [CI](https://github.com/alexsemenovru/awg-easy-3/actions/runs/45577609167/job/139079311131)
  Docker действительно заменил контейнер после имитации прерывания в этой точке.
  Основной узел подтвердил версию после подписанного сообщения из нового
  контейнера. Реестр и проверка подписи этого тестового образа заменены
  локальной фикстурой, поскольку следующая версия ещё не опубликована.
- В том же задании 943 Linux-теста прошли, один пропущен, ошибок нет.

## Восстановление Основного узла

- Проверка на отдельном Linux-раннере запускает два настоящих контейнера
  Ячеек и создаёт для них профили через API панели. После остановки исходного
  узла команда `restore.sh` разворачивает архив на чистой установке.
  Сценарий требует, чтобы обе Ячейки приняли новые полномочия и те же два
  клиентских профиля вновь открывали панель через AWG.
- Первый сквозной прогон дошёл до подтверждения поколения обеими Ячейками,
  затем выявил взаимную блокировку старта. Панель теперь поднимается с
  сохранёнными профилями, пока Ячейки публикуют свои параметры. Профиль
  отсутствующей Ячейки нельзя выгрузить или использовать на Основном узле.
- [Повторный прогон](https://github.com/alexsemenovru/awg-easy-3/actions/runs/45577609167/job/139079311352)
  прошёл. Обе Ячейки приняли полномочия восстановленного узла без перезапуска,
  подтвердили маршрутизацию, а два исходных профиля снова открыли панель.
  Адрес связи сохранился за переносимым тестовым IP.
- Журналы локальных попыток сохранены в игнорируемом `private-test-access`.
  Ubuntu и Debian выключены через SSH.
