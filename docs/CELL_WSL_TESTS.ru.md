## Пройдено на реальном AWG/nftables

- Запуск гостевой Ячейки без Home-клиента и без локальной веб-панели.
- Передача ICMP IPv4/IPv6 от тестового клиента через AWG и NAT/NAT66.
- IPv4 выключен: IPv4 блокируется, IPv6 работает.
- GeoIP block с синтетическими адресами WAN: обе семьи блокируются.
- Снятие ограничений восстанавливает передачу без переимпорта профиля.
- Искусственная ошибка применения nftables после изменения пиров: реальные
  `awg syncconf` откатывают пиров, старый конфиг сохраняется, guard остаётся.
- Успешный retry снимает guard; пустой список удаляет пиров.
- Остановка сохраняет специально созданную постороннюю nft-таблицу.

Первоначальный single-ping тест был слишком ранним после начального handshake;
проверка allow использует серию из трёх пакетов. Это не измерение потерь или SLA.
Имена/адреса синтетические, DNS сервиса и реальный интернет в тесте не используются.

## Повторяемость и границы

`download-cell-lab.cjs` загружает публичные OCI-слои; `run-cell-wsl-lab.sh`
поднимает только изолированную среду; `test-cell-runtime.cjs` выполняет тест.
Скрипт извлечения предназначен только для доверенного образа проекта, не для
произвольных OCI-архивов. Остаточные rootfs удаляются по точным проверенным
путям через cleanup-cell-wsl-lab.sh. После аварии их может потребоваться убрать.

OpenSSL добавлен в Dockerfile кандидата для подготовки служебных сертификатов;
новый образ с этим изменением ещё не собран. Использованный образ v0.1.6 не
содержит openssl CLI; TLS и сертификаты ранее проверены отдельными тестами Windows.

Ещё нужны VPS-тесты: разные серверы/провайдеры, установка/обновление службы,
сеть под потерями, реальный внешний IPv6 и маршрутизация между Основным узлом
и Ячейками. Межсерверные маршруты и DHT пока не реализованы; доставка настроек
уже проверена отдельным loopback TLS-тестом, но ещё не между VPS.
