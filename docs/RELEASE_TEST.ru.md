# Проверка чистой установки рядом с 3x-ui

Этот сценарий предназначен для временного тестового VPS после его очистки. Он
проверяет не только AWG-Easy 3, но и то, что установка не повреждает уже
работающую инфраструктуру.

## 1. Подготовить контрольную точку

Установить 3x-ui, убедиться, что открывается его панель и работает хотя бы одно
тестовое подключение. Затем сохранить вывод команд:

```bash
docker ps --format 'table {{.Names}}\t{{.Image}}\t{{.Ports}}'
docker network ls
ss -lntup
ip -brief address
ip route
ip -6 route
nft list ruleset
sysctl net.ipv4.ip_forward net.ipv6.conf.all.forwarding
```

Отдельно записать публичные порты 3x-ui, его контейнеры, сети Docker и имена
созданных им firewall-объектов. Выбранный UDP-порт AWG и VPN-подсети не должны
с ними пересекаться.

## 2. Установить AWG-Easy 3

Запустить штатный установщик, явно указав свободный публичный UDP-порт AWG,
внутренний порт панели и язык. Установщик должен остановиться с понятной
ошибкой при конфликте порта или подсети, а не изменять чужую конфигурацию.

## 3. Проверить AWG-Easy 3

- контейнер запущен и проходит healthcheck;
- наружу опубликован только выбранный UDP-порт AWG, TCP-порт панели отсутствует
  в публикациях Docker;
- первый профиль импортируется текущей AmneziaVPN через `vpn://`;
- через туннель работают IPv4 и, при наличии маршрута VPS, IPv6;
- Guest получает интернет, но не видит панель и VPN-подсети;
- два Home-клиента видят панель и друг друга;
- создание, отключение и удаление клиента применяются без перезапуска;
- после смены пароля старые сессии панели перестают работать;
- панель показывает состояние, текущую скорость, handshake и endpoint;
- mDNS/SSDP discovery проверяется двумя реальными Home-устройствами.

## 4. Проверить сосуществование

Повторить контрольные команды из первого пункта и сравнить результаты. Панель
3x-ui и её тестовое подключение должны продолжать работать.

Допустимые изменения AWG-Easy 3 ограничены:

- интерфейсом `awg0` и его адресами;
- таблицей nftables с префиксом `awg_easy_3`;
- помеченными правилами AWG-Easy 3 в `DOCKER-USER`;
- собственным sysctl-файлом проекта;
- собственными контейнером, образом, volume и сетью Compose;
- выбранным публичным UDP-портом AWG.

Контейнеры, сети, правила, порты и файлы 3x-ui не должны быть изменены,
перезапущены или удалены установщиком AWG-Easy 3.

## 5. Проверить удаление

После теста удалить AWG-Easy 3 штатной командой и снова сравнить контрольную
точку. Объекты проекта должны исчезнуть, а 3x-ui — сохранить работоспособность
и свои исходные настройки.
