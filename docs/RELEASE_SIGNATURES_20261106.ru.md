# Подпись стабильного пакета обновления

Будущий release workflow подписывает **конкретный digest**, а не изменяемый тег,
через Cosign и GitHub Actions OIDC. Подпись включает версию и git revision.
Публикация GitHub Release разрешается workflow только после проверки своей
подписи с точной identity `docker-publish.yml@refs/tags/v<version>` и issuer
`https://token.actions.githubusercontent.com`.

Реализация соответствует [Sigstore CI Quickstart](https://docs.sigstore.dev/quickstart/quickstart-ci/)
и [проверке сертификатной identity](https://docs.sigstore.dev/cosign/verifying/verify/).
Официальный образ Cosign 3.1.4 закреплён digest в updater; action установщика
закреплён commit SHA. Верификатор не запускается из проверяемого образа.
Он работает в отдельном краткоживущем контейнере без capabilities, host mounts
и Docker socket, с read-only rootfs, 192 MiB памяти и пониженным CPU share.
При ошибке/тайм-ауте удаляется только точный ID этого контейнера.
Доступ к Docker socket из Ячейки для этого не открывается.

Standalone updater проверяет digest, identity, issuer, версию и git revision
**до изменения checkout/перезапуска**. После проверки Compose использует digest,
чтобы последующая смена тега не подменила проверенный образ. Недоступная подпись,
GitHub/GHCR/Sigstore или несовпадение метаданных оставляют установку работающей.
Дополнительная загрузка Cosign происходит при первом фактическом обновлении;
ежедневная проверка без новой версии его не скачивает. Измеренный размер слоёв
официального образа на amd64 около 64 MiB; отдельный 139 MiB бинарник на хост
не устанавливается. Образ остаётся в Docker cache для следующих обновлений.

Это проверка артефактов обновления, не TLS-связь Main↔Cell и не HTTPS панели.
Автоматическая координация замены Main/Cell остаётся отдельным незавершённым
блокером: запрет panel-only обновления при включённом Main не снят.
Первую проверку **нашей собственной** опубликованной подписи можно провести
только при отдельно согласованном выпуске; этот коммит ничего не публикует.
Ранее опубликованные неподписанные образы намеренно не проходят новую проверку.

На Ubuntu настоящий ограниченный контейнер Cosign успешно проверил официальную
подпись своего образа по опубликованной Sigstore identity/issuer и отверг
неподписанный исторический образ AWG-Easy 3. Проверки updater подтверждают
сохранение установки при отказе подписи и запуск по digest при успехе.
