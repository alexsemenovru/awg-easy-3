## Важные решения

- Источник DB-IP Lite оставляем: на VPS загрузка исправна. DNS/GeoSite не добавлять.
- Включение GeoIP переводит состояние в v2, сохраняющийся даже после выключения
  фильтра. Старый код отвергает v2. Корневой STATE_VERSION пока 1 для совместимого
  обновления установок без включения GeoIP. Проверить взаимодействие с rollback.
- Профили/ключи временного VPS для продолжения не нужны; новые создаются на новом
  сервере. Никаких зависимостей от живого старого VPS для сохранённых результатов.
- Подробные результаты: GEOIP_DATABASE.md. Порядок будущего прогона:
  GEOIP_VPS_RUNBOOK.ru.md. Автоматизированный preflight: scripts/test-geoip-vps.sh.
