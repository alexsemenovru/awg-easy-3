# Точка продолжения: Основной узел и Ячейки

Сохранено 2026-09-14 перед перерывом. Это локальный прототип, **не релиз**.
Существующая панель и VPN не подключены к новым компонентам. VPS не требуется
для ближайшей локальной работы; старые тестовые VPS уничтожены, не подключаться.

## Реализовано

- CellInvitation: одноразовые приглашения, срок/отзыв, погашение и повтор запроса.
- CellEnrollmentStore: атомарное постоянное состояние регистрации Основного узла.
- ControlIdentityStore: постоянные Ed25519-ключи, явное создание без перезаписи.
- CellRegistration: подпись запроса и подтверждения, привязка к сторонам и запросу.
- CellRegistrationService/Handler: запись до подтверждения, строгий вход, лимиты.
- CellRegistrationTransport: TLS 1.3, ALPN, pin ключа до отправки секрета,
  ограничение сообщения и времени. Сервер сам не вызывает listen.
- ControlCertificateStore: локальный самоподписной сертификат через OpenSSL,
  продление без смены идентичности, без внешних CA и DNS.
- CellRegistrationEndpoint: соединение компонентов для служебной регистрации.
- CellConnectionStore: сохранённый запрос Ячейки для повтора, сохранение привязки
  после подтверждения без секрета приглашения.
- CellSettings/Receiver: подписанные версии, received/applied, отказ старым
  и конфликтующим версиям, восстановление последней applied через адаптер.

## Что проверено и что не следует преувеличивать

Тесты: регистрация, подписи/подмена, запись/сбои, повторное открытие хранилищ,
loopback TLS с реальными постоянными хранилищами обеих сторон, чужой pin без
отправки секрета, самоподписной сертификат и продление. Общий набор запускался
на Windows с Node и Git sh. Linux-проверка прав файла пропускается на Windows.
Применение настроек тестировалось **с имитацией адаптера**, не на AWG/nftables.
Рабочей VPN-Ячейки, DHT или установщика --slave пока нет.

Контрольный прогон перед коммитом: 281 тест, 280 прошли, 0 ошибок,
1 пропущен (Linux-права на Windows). `git diff --cached --check` без ошибок.
Ветка сохранения: `codex/cells-foundation`. Изменения не публиковались в релиз.

Продолжение после checkpoint: добавлена CellSettingsSchema (назначения клиентов),
подключена как стандартная validate-функция получателя. Генератор основной панели
пока не переиспользовать напрямую: он требует хотя бы одного Home, а Ячейка
может иметь пустой список или только Guest. Реального адаптера всё ещё нет.

Последнее продолжение: CellArtifacts проверяет локальные VPN-подсети и генерирует
AWG + headless nftables для входа и выхода на этой же Ячейке. CellRuntimeAdapter
переиспользует RuntimeApplier с отдельной временной drop-таблицей; при ошибке
оставляет трафик закрытым до retry/restore. Путь реальных команд добавлен, но
AWG-применение ещё проверено только имитацией runner. Синтаксис основной политики
и guard прошёл настоящий nft -c в изолированном namespace локальной Ubuntu WSL.
Межсерверные маршруты и доставка снимков по сети пока отсутствуют.

Следующая необходимая проверка — реальное применение/откат с AWG. Локальная WSL
имеет nft и /dev/net/tun, но не имеет awg, Docker, Go или C-компилятора. Возможны
временный тестовый Linux VPS либо согласованная установка тестовой среды локально.
До проверки не объявлять runtime готовым и не включать в основной запуск.

## Известные границы/вопросы

- Хранилища рассчитаны на один процесс-владелец; очереди только внутри процесса.
  CLI должен обращаться к службе. Не использовать алиасы одного файла.
- Повтор регистрации ограничен пятью минутами запроса и сроком приглашения.
  Длительный простой pending требует отдельного операторского сценария; не
  маскировать это автоматической заменой ключа/привязки.
- apply обязан откатывать частичные изменения. Сбой записи applied после изменения
  runtime остаётся неоднозначным исходом; нужен безопасный повтор/восстановление.
- Сертификат обновляется при ensure, не фоновым таймером. Pin — источник доверия;
  срок сертификата не является отзывом полномочий. Restore/смена власти ещё нет.
- Секреты pending хранятся в приватных файлах. Удаление из JSON не стирает снимки
  диска. Уборку временных ключей после аварийного завершения ещё подключить.
- Лимиты/схемы и TLS пока прототип: требуется проверка на Linux и нагрузочные тесты
  до публичного включения. Не открывать служебный listener автоматически.
