# Узлы и Ячейки: второй цикл маршрутизации и интерфейса, 29 октября

## Сделано

- Восстановление Ячейки принимает эквивалентный порядок элементов анонимного
  nftables-набора после чтения из ядра (`ce199afd`).
- Ячейка подтверждает подписанную ревизию маршрута только после применения и
  проверки правил и снятия пользовательского guard. Основной узел сверяет ACK
  с текущей ревизией; до подтверждения панель не объявляет вход готовым и не
  выдаёт профиль входа через Ячейку (`ecc3891e`). Старые снимки без ACK
  считаются неподтверждёнными до следующей синхронизации.
- Группы Home 1–10 изолированы в локальном firewall, межсерверных маршрутах и
  ретрансляторе обнаружения. `home` в старом состоянии соответствует группе 1,
  `guest` — «Выкл.»; ключи и конфиги не пересоздаются. В панели вместо
  переключателя выбирается «Выкл.» или номер группы (`7584312a`).
- Опциональная сверка правил с ядром nft в отдельном сетевом пространстве WSL
  подтвердила маршрут с двумя разными Home-группами (`e7d13623`).

## Проверено и не проверено

- `pnpm -C src test`: 803 теста, 761 успешен, 42 пропущены на Windows,
  ошибок нет. `AWG_NFT_KERNEL_TEST=1` в WSL: 3 успешных.
- Полевой тест этих изменений пока не проведён. 29 октября владелец смог
  предоставить только одну VPS. В файле AMS.txt указан новый адрес
  72.56.79.17, но из Windows и WSL TCP/22 до него не установился. На VPS
  ничего не менялось. Повторить вход после подтверждения доступности SSH.
- Развёртывание на одной VPS плюс локальная роль в WSL возможно только после
  подготовки работающей сетевой связности и runtime; в текущем WSL есть nft,
  но нет Docker и AWG. Не считать его заменой двухсерверного полевого теста.
