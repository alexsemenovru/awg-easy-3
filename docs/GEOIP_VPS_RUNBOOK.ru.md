# Короткий прогон GeoIP на новом тестовом VPS

Предыдущий VPS уничтожен. Его результаты сохранены в `GEOIP_DATABASE.md`.
Не использовать прежний IP и не обращаться к личной рабочей панели автора.

## Подготовлено локально

- `scripts/test-geoip-vps.sh`: последовательный прогон пакетной матрицы, полной
  базы и производственного обновлятора. Остановка при первой ошибке, включая
  ошибку любого процесса в конвейере (`pipefail`). Сеть хоста не меняется:
  nftables проверяется в отдельных пространствах имён.
- `scripts/test-awg-upgrade.cjs`: проверка перехода с закреплённой v0.1.5 на
  кандидат и назад с прежними клиентами. Только собственные временные Docker
  объекты, без публикации портов. Этот сценарий проверяет состояние без GeoIP.
- `src/test/helpers/Dockerfile.geoip-preview`: тестовый образ с текущим кодом
  поверх закреплённого релиза. Это не замена сборке релизного Dockerfile.

## Порядок работы агента после выдачи доступа

1. Проверить новый IP, SSH, ОС, память, IPv4/IPv6 и отсутствие чужой инфраструктуры.
2. Установить стабильную панель; пароль и профиль сохранять отдельно от публичных
   журналов. Передавать только нужные исходники, без `private-test-access` и ключей.
3. Запустить preflight; сохранить обезличенный результат локально сразу после
   завершения. Полная DB-IP уже проверена, источник не менять.
4. Выполнить контейнерный upgrade/rollback без GeoIP. Сравнить профили, ключи и
   настройки, не выводя их в журнал. Ошибка healthcheck не считается успехом.
5. В отдельной тестовой установке включить GeoIP, проверить реальный VPN-трафик
   в обоих направлениях и семьях адресов, Home-доступ и неизменность других
   клиентов. Выбор тестовых IP сверять с загруженной базой, не с географией сайта.
6. Перезапустить с включёнными фильтрами; проверить сохранение правил и профиля.
7. На копии данных проверить отказ старого контейнера читать v2. Возвратить новый
   образ и проверить восстановление. Не отключать защиту формата ради отката.
8. Выдать автору доступ для короткой проверки с телефона. Релиз — только после
   результатов; не ждать следующего лимита ради сохранения журналов.

## Короткая проверка автора

- Импортировать выданный тестовый профиль, открыть панель по IPv4 и IPv6.
- Выбрать страны и сохранить фильтр; проверить ожидаемое разрешение/блокировку.
- Убедиться, что Home-панель доступна, затем вернуть фильтр в «Без фильтрации».

Если VPS уничтожен до конца: отметить незавершённые пункты, продолжить на новом
сервере. Нельзя считать проверки пройденными только потому, что UI сохранил выбор.
