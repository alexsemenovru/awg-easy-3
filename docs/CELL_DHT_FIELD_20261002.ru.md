# Mainline DHT: повторный полевой раунд, 2026-10-02

Испытаны две пустые тестовые VPS: MOW (Debian 11, libtorrent 1.2.9) и AMS
(Ubuntu 22.04, libtorrent 2.0.5). На обеих установлен только пакет
`python3-libtorrent` и скопирован `experiments/mainline-dht/probe.py`.
Основной AWG-канал, пользовательские профили и панель не затрагивались.

Оба пробника работали с отдельным UDP-портом 49033, тремя публичными
bootstrap-адресами и прямым bootstrap друг к другу. Параметр `--seconds 220`
ограничивал время процесса; `len(session.get_torrents())` оставался нулём.
Локальные firewall VPS не изменялись. В одном запуске MOW видел до 82 DHT-узлов
при пиковой RSS 22 976 КиБ, AMS — до 65 при 25 404 КиБ. Это короткий
диагностический срез, а не расчёт эксплуатационного лимита.

Каждая сторона опубликовала отдельную неизменяемую тестовую JSON-строку.
Публикация MOW получила 8 подтверждений, AMS — 7. AMS прочитал запись MOW
по SHA-1 и проверил содержимое. MOW сначала возвращал `null`, хотя трассировка
показала DHT-ответы с записью, SHA-1 которой точно совпадал с искомым.
Причина оказалась в Python-обвязке libtorrent 1.2.9: поле `alert.item.value`
содержало дополнительные внешние апострофы. Пробник теперь принимает такой
вариант только после повторной проверки SHA-1 bencoded-значения. С этим
исправлением MOW прочитал запись AMS; итоговый процесс завершился с кодом 0.

Вывод узкий: двусторонние put/get неизменяемой пробной записи работают между
этими версиями libtorrent через публичную Mainline DHT. Пока **не** проверены
подписанные изменяемые BEP 44 записи, стабильность после перезапуска, поиск
после смены IP, NAT, недоступность bootstrap-узлов, аутентифицированный
резервный служебный канал и ресурсные пределы под нагрузкой VPN. Это не
разрешение включать DHT в рабочую панель или передавать через неё команды.

На VPS не оставлялись работающие пробники. Установленный пакет
`python3-libtorrent` и тестовый скрипт оставлены для следующего раунда, пока
пользователь сохраняет эти две VPS. Секреты и клиентские данные не
публиковались и не включены в этот отчёт.
