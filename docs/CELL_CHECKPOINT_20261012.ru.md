## Что добавлено после предыдущего checkpoint

- Базовый журнал ревизий Основного узла создаётся до первого изменения AWG;
  прерванный первый join можно продолжить по сохранённому плану.
- Применение пользовательских настроек Ячейки использует durable nft guard.
  Он включается до boot-восстановления даже при утраченном постоянном плане,
  сохраняется при частичном сбое и снимается лишь после readback.
- Для таблицы пользовательских правил Ячейки сохраняется приватный отпечаток
  нормализованного kernel nft readback. Чужая или изменённая таблица не
  заменяется молча. При аварии между заменой таблицы и записью отпечатка
  возможна ручная диагностика под guard; автоматический recovery ещё не
  доказан для этого окна.
- `openCellSettingsRuntime` связывает доверенные ключи из регистрации,
  получатель подписанных настроек и постоянный журнал защиты.
- `CellHostPreflight` читает занятость имён интерфейсов, UDP-портов и
  nft-таблиц перед новой установкой без изменения сервера.
- Ячейка получает внутренний адрес управления только из подписанной
  регистрации и проверяет постоянный AWG-путь перед каждым обменом.
  `CellSettingsPoller` добавляет ограниченный backoff и обезличенный статус.
- `withCellInstallationLock` удерживает Linux `flock` через дескриптор Node.
  Механика наследуемого дескриптора подтверждена в WSL коротким тестом;
  сам Node-компонент на Linux ещё требует прогона.
- `openRegisteredCellHost` и `openRegisteredControllerHost` собирают
  существующие runtime под одним lock для boot/join/синхронизации. Это не
  первоначальная продуктовая установка.

`pnpm -C src test`: 601 тест, 566 успешных, 35 пропущены по условиям
платформы, 0 ошибок. `pnpm -C src check` также прошёл.
